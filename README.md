# Peresheek.GO Data

Открытый рабочий датасет мест Карельского перешейка для MVP Перешеек.GO.

## v0.2
- 100 записей
- JSON + CSV
- provenance/status у каждой записи
- PostGIS-ready схема
- непроверенные динамические факты не заполняются догадками

## Quality
`verified_source` — есть именованный источник.
`needs_details` — объект подтверждён источником, но карточка неполная.
`needs_primary_source` — нужен первичный источник.
`candidate` — кандидат; не публиковать в production до проверки.

## Data policy
Расписания транспорта, цены, часы работы и временные ограничения считаются
динамическими данными. Их следует получать из официальных API/источников и
кэшировать, а не считать постоянными свойствами объекта.
